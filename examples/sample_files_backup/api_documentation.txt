# API Reference - User Authentication Module

## Overview
This module handles user authentication using JWT tokens with refresh token rotation.

## Endpoints

### POST /api/v1/auth/login
Authenticates a user and returns access/refresh tokens.

**Request Body:**
```json
{
  "email": "user@example.com",
  "password": "secure_password"
}
```

**Response (200 OK):**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "refresh_token": "dGhpcyBpcyBhIHJlZnJl...",
  "expires_in": 3600
}
```

### POST /api/v1/auth/refresh
Rotates the refresh token and issues new access token.

### POST /api/v1/auth/logout
Invalidates current session and blacklists refresh token.

## Configuration

Environment variables:
- `JWT_SECRET`: Secret key for signing tokens (required)
- `ACCESS_TOKEN_TTL`: Access token lifetime in seconds (default: 3600)
- `REFRESH_TOKEN_TTL`: Refresh token lifetime in seconds (default: 604800)

## Error Codes
| Code | Description |
|------|-------------|
| 401  | Invalid credentials |
| 403  | Token expired or blacklisted |
| 429  | Rate limit exceeded |

## Example Implementation
```python
from auth import AuthService

auth = AuthService()
tokens = auth.login(email, password)
```
